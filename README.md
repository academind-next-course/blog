# Next.js Routing and Rendering

A hands-on project from the Academind Next.js course, covering page routing and rendering strategies in Next.js 14 with the App Router.

## Technologies

- [Next.js](https://nextjs.org/) 14.1 (App Router)
- [React](https://react.dev/) 18
- JavaScript (JSX)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

The dev server runs at [http://localhost:3000](http://localhost:3000).

## What You Learn

- File-based routing with the App Router
- Server-side vs client-side rendering
- Layouts and nested routing
- Static and dynamic page generation
